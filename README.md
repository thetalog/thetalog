### [`PIXL`](https://github.com/thetalog/pixl) // production social platform

**Pixl** is a full-stack, Instagram-style social platform built with **Nuxt 4 + Node.js/Express**, featuring OTP/JWT authentication, posts, reels, stories, likes, saves, comments, tags, follows, profiles, and user discovery. The platform also includes **real-time DMs, group conversations, typing/read receipts, live streaming, and live comments** powered by Socket.IO.
